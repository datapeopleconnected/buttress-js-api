# Security Policy

## Supported Versions

This package tracks the current Buttress server API. Security fixes are made against the `main` branch and
released as a new npm version; only the latest published version is supported.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report it privately using [GitHub's private vulnerability reporting](https://github.com/datapeopleconnected/buttress-js-api/security/advisories/new)
for this repository. Include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce, or a minimal proof of concept.
- The version of `@buttress/api` (and Buttress server, if relevant) you tested against.

We'll acknowledge your report as soon as we can, investigate, and keep you updated as we work on a fix. Once a
fix is released, we'll credit reporters (unless you'd prefer to stay anonymous) in the release notes.
